# タスク完了時のチェックリスト

## コードを書いた後に実行すべきこと

### 1. フォーマットの確認
```bash
cargo fmt
```

### 2. Lintチェック
```bash
cargo clippy
```

### 3. コンパイルチェック
```bash
cargo check
```

### 4. ビルド
```bash
cargo build
```

### 5. テストの実行（テストが存在する場合）
```bash
cargo test
```

### 6. ドキュメントのビルド（必要に応じて）
```bash
cargo doc
```

## プロジェクト全体での確認

### 複数のプロジェクトを変更した場合
```bash
cargo make build-stable
cargo make test-stable
```

## コミット前の確認
1. すべてのコードが正しくフォーマットされている
2. コンパイルエラーがない
3. Clippy警告が解決されている（または意図的に無視している）
4. テストが通っている
5. 新しいファイルが適切にGitに追加されている

## 注意事項
* このプロジェクトはサンプルコード集なので、各サンプルは独立して動作する
* 一つのサンプルの変更が他のサンプルに影響を与えることはない
* 各サンプルは教育目的なので、過度な最適化よりも明確性を優先する
