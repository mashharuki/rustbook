## 各プロジェクトの構成
各サンプルプロジェクトは標準的なCargoプロジェクト構造：
```
project_name/
├── Cargo.toml    - プロジェクト設定と依存関係
├── src/          - ソースコード
│   └── main.rs   - エントリーポイント（またはlib.rs）
└── tests/        - テストコード（存在する場合）
```

## ワークスペース
一部のプロジェクトはCargoワークスペースとして構成されている：
* `ch04/4-1/` - 複数のCLIサンプル
* `ch09/9-1/4_workspace/sample/` - ワークスペースの例

## 特殊なファイル
* `Makefile.toml` - cargo-make用のタスク定義
* `.gitignore` - Gitで無視するファイル（主に`target/`ディレクトリ）
* `LICENSE` - MITライセンス
* `README.md` - プロジェクト説明
